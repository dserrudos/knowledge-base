# Informe de Laboratorio: OoOps Machine

## Especificaciones Tecnicas
*   **Plataforma:** CTF Training-B
*   **Dificultad:** Media
*   **Categoria:** Boot2Root / Linux
*   **Enfoque:** Analisis de servicios, explotacion de vulnerabilidades y escalada de privilegios.

## Resumen del Proyecto
Este repositorio documenta el proceso de intrusion y compromiso de la maquina OoOps. El analisis se centra en la identificacion de configuraciones inseguras en servicios estandar y la explotacion de vulnerabilidades conocidas en binarios del sistema.

## Objetivos de Aprendizaje
1.  Enumeracion de servicios criticos (FTP, HTTP, SSH).
2.  Explotacion de carga de archivos no restringida (Arbitrary File Upload).
3.  Analisis de exposicion de credenciales en procesos del sistema.
4.  Bypass de politicas de seguridad en Sudo (CVE-2019-14287).
